# Sentry v2.0.0 — Windows Stable

Windows 11 x64 + WSL2, with Ubuntu preferred. This is a major release: it removes the
1.x merge, verification and issue features and adds staged QA, project profiles,
toolchains, re-test of earlier findings and more. The unsigned archive uses online Linux
runtime bootstrap. See the [official Release page](https://github.com/Mert1026/Sentry/releases/tag/v2.0.0)
for exact source identity, ZIP/checksum and PowerShell commands for both fresh
installation and updating an existing installation.

## Breaking changes

- The merger, verifier, issue and retest services, pages and CLI commands
  (`run merge`, `issue`, `retest`, `verify`) are removed.
- Database migration 7 is **one-way**: it drops the merge, verification, issue and retest
  tables and legacy retest runs. Full and Targeted runs, findings, evidence and exports
  are kept; issue and retest history is not. Back up the data folder before updating,
  and do not downgrade a migrated database to 1.x.

## Included

- Staged QA flow: a frozen plan, per-check investigation, deepening, a hazard sweep and a
  report, with a proof gate and an operation receipt.
- Re-test of earlier findings on the current revision. Each finding is one check, answered
  Passed, Not passed or Could not complete with the agent's reason.
- Findings by revision, and a project profile with per-agent notes (labelled unverified,
  never holding past findings).
- Toolchains: a library of 59 packs, project-pinned versions, custom add-ons, and a
  per-run option to allow tool and SDK downloads.
- ChatGPT as an opt-in agent next to OpenCode, DeepSeek and GLM.
- CLI parity for all of the above. See the [CLI reference](../beta/cli.md).
- Bulgarian interface translations, including statuses and generated text.
- Containment fixes: project copy, update, delete and recovery never follow symbolic
  links below the data root.

## Updating an existing installation

Use the Release page's **Update an existing installation** PowerShell block. Finish or
cancel active work, stop Sentry and back up the stopped runtime data and Desktop
profile. Download and verify the exact ZIP and sidecar, extract to a separate directory,
run its setup and tools, then open a new terminal and verify the version, existing
projects and runs, and `sentry cli capabilities --json`. Keep the previous archive and
backup until you accept the result. There is no automatic updater. See the
[upgrade and recovery guide](../setup/distribution.md#explicit-release-upgrade-repair-and-source-beta-migration)
and [compatibility](../beta/compatibility.md).

## Compatibility and verification limits

Product version 2.0.0, runtime protocol 1. Provider and model pins, secure settings and
revision hash formats are unchanged. Only the Python and .NET toolchain installers have
been run end to end; the other packs are covered by unit tests. Native Linux Desktop is
deferred. Setup needs internet. There is no signed installer, offline install, automatic
updater or macOS support. Paid QA runs are separate operator actions.
