# Sentry v0.1 Beta

First public user-facing Beta. Clone the repository, run one setup command,
use the application — no monorepo knowledge required.

> Install from a Git clone (not the source ZIP): `sentry update` needs a
> Git checkout to track Beta fixes.

## What's included

- Desktop QA workspace: dashboard, projects, run workspace, finding
  inspection, evidence views, JSON/log export with native Save As.
- Full QA and Targeted QA across three independent agents: OpenCode
  (1.18.32), DeepSeek (SDK 0.1.5-rc.2), GLM (Claude Code 2.1.270).
- WSL2 execution runtime with isolated workspaces and handshake verification.
- Secure provider settings via the Desktop UI (safeStorage / DPAPI).
- `sentry` launcher: setup, open, update, stop, status, doctor, version.
- Responsive redesigned UI (app shell, core pages, system pages, run
  workspace).

## Requirements

- Windows 11, internet access during setup.
- WSL2 — reused if present (Ubuntu preferred), installed otherwise
  (may need Administrator approval and a reboot; setup resumes after).
- Node >= 22, pnpm 9.12.3 (setup guides/installs).
- Provider accounts/API credentials for the agents you run.

## Installation

```powershell
git clone https://github.com/Mert1026/Sentry.git
cd Sentry
.\sentry.ps1 setup
sentry open
```

Then: Settings → Providers → configure accounts; Environment → verify;
add a project; start Full QA.

## Updating

`sentry update` pulls the latest commits from `main` (fast-forward only,
refuses on dirty trees) and rebuilds + redeploys + reopens. GitHub Releases
are milestones, not the update source, for this Beta.

## Agent configuration

All provider credentials and model selections live in Settings → Providers
in the Desktop app. Setup never asks for secrets. Settings persist across
updates.

## Known limitations

- Windows + WSL2 only for this Beta.
- Source-based installation; no signed `.exe` installer yet (electron-builder
  config exists but installers come after the source Beta is proven).
- Setup may require a Windows reboot when installing WSL.
- Provider access/keys required to run agents.
- Update tracks latest `main` commits rather than Releases.
- Beta software: expect rough edges; bug reports welcome (see below).

## Reporting bugs

Run `sentry doctor`, then include: Sentry version + commit (`sentry
version`), Windows version, WSL distro, the failing command, expected vs
actual behavior, reproduction steps, `sentry status -Json` output, and the
FAIL/WARN doctor lines. Never paste API keys or tokens.
